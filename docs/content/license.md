## The license

FileGator is licensed under the **MIT License**. Copyright (c) 2026 Milos
Stojanovic and contributors. The full text is in
[LICENSE](https://github.com/filegator/filegator/blob/master/LICENSE) in the
repository.

### What that means

- **Use it however you like.** Running FileGator, privately or commercially, is
  unrestricted. Nobody has to publish anything for using it.
- **Modify it and keep your changes to yourself.** There is no obligation to
  share modifications, and no obligation to publish source when you offer a
  modified version to others over a network.
- **If you distribute it**, the copyright notice and the permission notice must
  travel with it.
- **No warranty.** The software comes as-is.

The whole license is a few paragraphs, so there is no "what does this clause
mean for me" question to answer: the only condition is keeping the copyright
and permission notice in copies and substantial portions of the software.

Bundled third-party Go modules keep their own licenses; each carries its
`LICENSE` file inside `vendor/`. The documentation bundles the Liberation Sans
font under the SIL Open Font License 1.1 — see `docs/static/fonts/OFL.txt`.

## Contributing

Please note we have a code of conduct, please follow it in all your interactions with the project.

- Before starting to write code, talk to a maintainer and discuss proposed changes
- File an issue before submitting a pull request
- Please make sure continuous integration passes

You keep the copyright of your contribution, and it is licensed under the MIT
License like the rest of the project.

## Where to report bugs?

- Please report all bugs in this repository's issues tracker.
